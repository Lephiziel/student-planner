# API Documentation — Student Planner

Базовый URL: `http://localhost:8080/api`

Все защищённые эндпоинты требуют заголовок:

```
Authorization: Bearer <access_token>
```

Формат ответа:
- Успех: `{ "success": <данные> }`
- Ошибка: `{ "error": "<сообщение>" }`

---

## 1. Auth — `/auth`

### POST `/auth/register`

Регистрация нового пользователя.

**Тело запроса:**
```json
{
  "name": "Иван Иванов",
  "email": "student@example.com",
  "password": "12345678"
}
```

| Поле | Правила |
|---|---|
| `name` | обязательно, минимум 2 символа |
| `email` | обязательно, валидный email |
| `password` | обязательно, минимум 8 символов |

**Ответы:**
| Код | Когда |
|---|---|
| `201` | Пользователь создан |
| `400` | Невалидные данные |
| `409` | Email уже зарегистрирован |

**Пример успешного ответа (201):**
```json
{
  "success": {
    "id": 1,
    "email": "student@example.com",
    "name": "Иван Иванов"
  }
}
```

---

### POST `/auth/login`

Вход пользователя, выдача токенов.

**Тело запроса:**
```json
{
  "email": "student@example.com",
  "password": "12345678"
}
```

**Ответы:**
| Код | Когда |
|---|---|
| `200` | Успешный вход |
| `400` | Невалидные данные |
| `401` | Неверный email или пароль |

**Пример успешного ответа (200):**
```json
{
  "success": {
    "access_token": "eyJ...",
    "refresh_token": "eyJ..."
  }
}
```

> `access_token` живёт 15 минут, `refresh_token` — 7 дней.

---

### POST `/auth/refresh`

Получение нового access-токена по refresh-токену.

**Тело запроса:**
```json
{
  "refresh_token": "eyJ..."
}
```

**Ответы:**
| Код | Когда |
|---|---|
| `200` | Новый access-токен выдан |
| `400` | Невалидное тело запроса |
| `401` | Невалидный или просроченный refresh-токен |

**Пример успешного ответа (200):**
```json
{
  "access_token": "eyJ..."
}
```

## 2. Users — `/users` 🔒

### GET `/users/me`

Возвращает данные текущего авторизованного пользователя.

**Ответы:**
| Код | Когда |
|---|---|
| `200` | Успех |
| `401` | Токен отсутствует или невалиден |
| `404` | Пользователь не найден |

**Пример ответа (200):**
```json
{
  "success": {
    "id": 1,
    "email": "student@example.com",
    "name": "Иван Иванов"
  }
}
```

---

## 3. Subjects — `/subjects` 🔒

Предметы принадлежат пользователю — каждый видит и редактирует только свои.

### GET `/subjects/`

Список всех предметов текущего пользователя.

**Ответ (200):**
```json
{
  "success": [
    { "ID": 1, "user_id": 1, "name": "Математика", "color": "#a78bfa" }
  ]
}
```

---

### GET `/subjects/stats`

Статистика по каждому предмету: количество задач и количество выполненных.

**Ответ (200):**
```json
{
  "success": [
    {
      "subject_id": 1,
      "subject_name": "Математика",
      "color": "#a78bfa",
      "total_tasks": 5,
      "done_tasks": 3
    }
  ]
}
```

---

### POST `/subjects/`

Создание предмета.

**Тело запроса:**
```json
{
  "name": "Математика",
  "color": "#a78bfa"
}
```

| Поле | Правила |
|---|---|
| `name` | обязательно, минимум 2 символа |
| `color` | опционально |

**Ответы:** `201` создан, `400` невалидные данные.

---

### PUT `/subjects/:id`

Обновление предмета. Тело запроса — как при создании.

**Ответы:** `200` обновлён, `400` невалидные данные, `404` предмет не найден / не принадлежит пользователю.

---

### DELETE `/subjects/:id`

Удаление предмета.

**Ответы:** `200` `{ "message": "deleted" }`, `404` предмет не найден / не принадлежит пользователю.

---

## 4. Tasks — `/tasks` 🔒

### GET `/tasks/`

Список задач текущего пользователя с фильтрацией.

**Query-параметры (все опциональны):**

| Параметр | Описание | Пример |
|---|---|---|
| `status` | Фильтр по статусу | `todo`, `in_progress`, `done` |
| `priority` | Фильтр по приоритету | `low`, `medium`, `high` |
| `subject_id` | Фильтр по предмету | `1` |
| `search` | Поиск по названию (ILIKE) | `матем` |
| `due_from` | Дедлайн от даты | `2026-06-01` |
| `due_to` | Дедлайн до даты | `2026-06-30` |

**Ответ (200):**
```json
{
  "success": [
    {
      "ID": 5,
      "user_id": 1,
      "subject_id": 1,
      "title": "Сделать лабораторную",
      "description": "По теме графы",
      "due_date": "2026-06-15T00:00:00Z",
      "priority": "high",
      "status": "todo"
    }
  ]
}
```

---

### GET `/tasks/stats`

Сводная статистика по задачам пользователя.

**Ответ (200):**
```json
{
  "success": {
    "total": 10,
    "done": 4,
    "in_progress": 3,
    "todo": 2,
    "overdue": 1
  }
}
```

> Просроченная задача — `due_date < now` и `status != done`.

---

### POST `/tasks/`

Создание задачи.

**Тело запроса:**
```json
{
  "title": "Сдать лабораторную",
  "description": "По теме графы",
  "due_date": "2026-06-15T00:00:00Z",
  "priority": "high",
  "status": "todo",
  "subject_id": 1
}
```

| Поле | Правила |
|---|---|
| `title` | обязательно, минимум 2 символа |
| `description` | опционально |
| `due_date` | опционально, ISO 8601 |
| `priority` | обязательно, одно из: `low`, `medium`, `high` |
| `status` | обязательно, одно из: `todo`, `in_progress`, `done` |
| `subject_id` | опционально |

**Ответы:** `201` создана, `400` невалидные данные, `401` без токена.

---

### PUT `/tasks/:id`

Обновление задачи. Тело — как при создании.

**Ответы:** `200` обновлена, `400` невалидные данные, `404` задача не найдена / не принадлежит пользователю.

---

### PATCH `/tasks/:id/status`

Изменение только статуса задачи.

**Тело запроса:**
```json
{
  "status": "done"
}
```

**Ответы:** `200` `{ "message": "updated" }`, `400` невалидный статус, `404` задача не найдена.

---

### DELETE `/tasks/:id`

Удаление задачи.

**Ответы:** `200` `{ "message": "deleted" }`, `404` задача не найдена / не принадлежит пользователю.

---

## 5. Grades — `/grades` 🔒

Самооценка — студент сам оценивает выполненную задачу и оставляет комментарий.

### GET `/grades/?task_id={id}`

Получить самооценки по конкретной задаче.

**Ответ (200):**
```json
{
  "success": [
    { "ID": 3, "task_id": 5, "user_id": 1, "score": 4.5, "feedback": "Хорошая работа" }
  ]
}
```

**Ответы:** `400` если `task_id` не передан/невалиден, `401` без токена.

---

### POST `/grades/`

Создание самооценки для задачи.

**Тело запроса:**
```json
{
  "task_id": 5,
  "score": 4.5,
  "feedback": "Хорошая работа, но есть замечания"
}
```

| Поле | Правила |
|---|---|
| `task_id` | обязательно, задача должна принадлежать пользователю |
| `score` | обязательно, от 1 до 5 |
| `feedback` | опционально |

**Ответы:** `201` создана, `400` невалидные данные, `404` задача не найдена / не принадлежит пользователю.

---

### PUT `/grades/:id`

Обновление самооценки.

**Ответы:** `200` обновлена, `400` невалидные данные, `404` оценка не найдена / не принадлежит пользователю.

---

### DELETE `/grades/:id`

Удаление самооценки.

**Ответы:** `200` `{ "message": "deleted" }`, `404` оценка не найдена / не принадлежит пользователю.

---

## 6. Health Check

**Ответ (200):**
```json
{ "status": "ok" }
```
